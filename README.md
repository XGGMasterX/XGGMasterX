I am the founder of three open-source organizations focused on graphics technology, game development, and artificial intelligence:

- **[FunshiEngine](https://github.com/FunshiEngine)** — An organization dedicated to the development of **FunshiEngine**, an open-source game engine built with C++.

- **[KromaxGFX](https://github.com/KromaxGFX)** — An organization dedicated to the development of **Kromax**, an independent, open-source graphics API designed to explore low-level graphics programming and rendering technologies.

- **[Nootechnia](https://github.com/Nootechnia)** — An organization dedicated to open-source artificial intelligence research and development.

My work across these organizations reflects a commitment to open-source development, mathematical foundations, technical innovation, and building software from the ground up. I believe that meaningful technological progress comes from sharing knowledge, designing sound architectures, and making research accessible to everyone.
